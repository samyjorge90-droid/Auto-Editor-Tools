Instalar Auto Editor Tools

O teu navegador não ofereceu o botão automático. Faz assim:

  • Chrome / Quetta no Android: toca no menu ⋮ e escolhe «Instalar app» ou «Adicionar ao ecrã principal».
  • Chrome / Edge no computador: clica no ícone de instalar na barra de endereço, ou no menu ⋮ → «Guardar e partilhar» → «Instalar».
  • iPhone / iPad (Safari): toca em Partilhar → «Adicionar ao ecrã principal».

Só é possível instalar quando a página está aberta pelo endereço https (por exemplo, o do GitHub Pages) e não a partir de um ficheiro guardado no telemóvel.
